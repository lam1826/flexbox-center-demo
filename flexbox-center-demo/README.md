# Thực hành CSS Flexbox – Căn giữa hoàn hảo

Bài thực hành căn giữa một thẻ thông báo (card) theo cả chiều ngang và chiều dọc của màn hình bằng Flexbox.

## Thành phần

- `index.html`: Cấu trúc HTML của trang.
- `style.css`: CSS với `display: flex`, `justify-content: center` và `align-items: center`.

## Chạy trên máy tính

Mở `index.html` trong trình duyệt hoặc chọn **Open with Live Server** trong Visual Studio Code.

## Đưa lên GitHub để lấy link minh chứng

1. Tạo một repository công khai trên GitHub, ví dụ `flexbox-center-demo`.
2. Upload ba file `index.html`, `style.css`, `README.md` vào **thư mục gốc** của repository.
3. Vào **Settings → Pages**.
4. Trong **Build and deployment**, chọn **Deploy from a branch**; chọn nhánh **main**, thư mục **/(root)** và nhấn **Save**.
5. Chờ GitHub Pages triển khai, sau đó mở link được hiển thị trong phần Pages để kiểm tra.

Nếu repository tên là `flexbox-center-demo`, địa chỉ thường có dạng:

`https://TEN-TAI-KHOAN.github.io/flexbox-center-demo/`

Thay `TEN-TAI-KHOAN` bằng tên GitHub thực tế của bạn. Đây chỉ là mẫu URL, không phải link đã được xuất bản.

## Kiểm tra hoàn thành

- Card nằm giữa theo chiều ngang và chiều dọc.
- Card vẫn được căn giữa khi thay đổi kích thước cửa sổ.
- Màu nền xám nhạt, card nền trắng, góc bo tròn và đổ bóng nhẹ.

## Nội dung nộp bài

Nộp link GitHub Pages sau khi triển khai thành công và, nếu cần, link repository chứa mã nguồn.
